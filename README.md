#  Python To-Do List

A simple command-line To-Do List application built with Python. This project helps users manage their daily tasks by adding, viewing, updating, and deleting tasks.

##  Features

-  Add new tasks
-  View all tasks
-  Update existing tasks
-  Delete completed or unwanted tasks
-  Simple command-line interface
-  Built using Python

##  Technologies Used

- Python 3

##  Project Structure

```
Python-Intern/

```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Ali-Hamza01/Python-Intern.git
```

2. Navigate to the project folder:

```bash
cd Python-Intern
```

3. Run the program:

```bash
python To_Do_Lists.py
```
