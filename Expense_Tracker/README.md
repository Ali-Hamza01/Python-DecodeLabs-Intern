# Expense Tracker

## DecodeLabs - Project 2

This project is a simple **Expense Tracker** developed using Python. It allows users to enter multiple expenses and calculates the total amount spent.

## Project Goal

The goal of this project is to understand:

* Python input and output
* Variables
* Mathematical operations
* `for` loops
* Accumulator logic

The main accumulator logic used in this project is:

```python
total = total + new_expense
```

## How It Works

1. The program asks the user how many expenses they want to enter.
2. The user enters each expense amount.
3. The program adds each expense to the total.
4. After all expenses are entered, the program displays the **Total Spent**.

## Example

```text
================================
        EXPENSE TRACKER
================================
How many expenses do you want to enter? 3
Enter expense 1: 100
Enter expense 2: 50
Enter expense 3: 20
--------------------------------
Total Spent: 170.00
--------------------------------
```
